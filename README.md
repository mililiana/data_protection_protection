#Project: Information security

## Project Description.
This project demonstrates various methods of information protection, including encryption and digital signature. The implementation is made in Flask and supports running through the `app.py` file. The project uses public and symmetric key encryption algorithms, as well as digital signature generation.

## Implemented functionality.
- Public key encryption (RSA)
- Symmetric key encryption (RC5)
- Hashing (MD5)
- Linear congruent pseudo-random number generator*****.
- Digital signature (DSA)

### Startup instructions
1. Clone the repository:
   git clone https://github.com/mililiana/data_protection_protection.git
   cd dsa_app

2. Run the application:
   ```bash
   python app.py
   ```

3. Go to the web browser at the address:
   ```
   http://127.0.0.1:5000
   ```

## Usage examples
- RSA: Encrypting and decrypting text data using a pair of public and private keys.
- RC5: Symmetric encryption to protect sensitive information.
- MD5: Generates a hash to verify the integrity of files.
- Linear generator: Generate pseudo-random numbers for cryptographic tasks.
- DSA: Signing and verifying digital signatures to guarantee data authenticity.
